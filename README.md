# Мониторчики

Сайт детского электронного издания об интернет-безопасности.

Проект разработан для публикации образовательных материалов, которые помогают детям и родителям лучше ориентироваться в цифровой среде и безопаснее пользоваться интернетом.

## О проекте

В рамках проекта была реализована полноценная структура многостраничного сайта:

* главная страница;
* разделы с материалами для детей и родителей;
* страницы отдельных публикаций;
* карточки статей и образовательных материалов;
* раздел с играми и интерактивным контентом;
* материалы для скачивания;
* адаптивная навигация;
* мобильная версия сайта.

Особое внимание при разработке уделялось понятной структуре интерфейса, яркому визуальному стилю и удобству использования сайта на разных устройствах.

## Результат

Получился адаптивный образовательный сайт с несколькими типами контента и единым визуальным стилем, рассчитанный как на детскую аудиторию, так и на родителей.

## Обязательные SEO-редиректы nginx

Сайт должен быть доступен для индексирования только на `https://monitorchiki.ru`.
В конфигурации nginx перенаправить HTTP и `www` на канонический хост:

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name monitorchiki.ru www.monitorchiki.ru;

    return 301 https://monitorchiki.ru$request_uri;
}

server {
    listen 443 ssl;
    listen [::]:443 ssl;
    server_name www.monitorchiki.ru;

    # Используйте те же ssl_certificate и ssl_certificate_key,
    # что и в существующем HTTPS-сервере.
    return 301 https://monitorchiki.ru$request_uri;
}
```

В существующий HTTPS-блок `server_name monitorchiki.ru` добавить редирект дубля:

```nginx
location = /index.html {
    return 301 https://monitorchiki.ru/;
}
```

После изменения проверьте конфигурацию командой `nginx -t` и только затем перезагрузите nginx.
